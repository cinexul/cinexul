# 暗室技术手册 —— GitHub Profile 到底能玩到多复杂

> 本文回答两个问题:**① README 自定义的天花板在哪里;② 这个仓库的每个效果是怎么实现的。**
> 结论先行:README 不给你 CSS,但给了你一扇后门——`<img>` 里的 SVG 是一份完整的独立文档,
> 内部的 CSS 动画 / 滤镜 / 渐变 / 蒙版全部生效。再叠加 GitHub Actions 与边缘函数,
> 你能做到的事情非常接近"一个不能点击的网页 + 定时/按请求更新的数据"。

---

## 一、规则:什么被杀,什么活着

GitHub 渲染 README 时用白名单 sanitizer 清洗 HTML:

| 被杀 | 活着 |
|---|---|
| `<style>`、`style=""` 内联样式 | `<img>`(含 `width/height/align/alt`) |
| `<script>`、一切事件属性 | `<picture>` + `<source media="(prefers-color-scheme)">` |
| `<iframe>`、`<embed>`、`<object>` | `<a>`(可以包住 `<img>`) |
| 表单、输入控件 | `<details>/<summary>`(唯一的原生交互!) |
| 自定义字体加载 | `<table>`、`<kbd>`、`<sub>/<sup>`、HTML 注释 |

所有外链图片都被 GitHub 的 **camo 代理**转发(匿名化 + 缓存)。关键推论:

1. **SVG 经 camo 后仍然是 SVG**,浏览器把它当独立文档渲染:
   内部 `<style>`、CSS `@keyframes`、SVG 滤镜(feGaussianBlur/feDropShadow/feTurbulence…)、
   渐变、蒙版、`clip-path`、`pattern`、data URI 内嵌图片 **全部可用**。
2. SVG 内部**不能**:跑 JS、请求任何外部资源(字体/图片必须内嵌为 data URI 或用系统字体栈)、
   响应鼠标(`:hover` 无效,`<img>` 不把指针事件传进文档)。
3. camo 有缓存:raw.githubusercontent.com 的 `Cache-Control: max-age=300` 决定了
   README 里的相对路径图片**约 5 分钟内刷新**;自建服务想每次请求都变,
   响应头要发 `Cache-Control: no-cache, no-store, must-revalidate`。

## 二、六层楼:由平庸到天花板

**L0 · Markdown + emoji + 徽章** —— 平庸的原因:只有内容,没有版面与动态。

**L1 · 现成的动态图服务** —— github-readme-stats、typing-svg、snake、lowlighter/metrics。
本质都是"别人服务器渲染的 SVG"。千人一面,自定义空间小。大多数"看起来花哨"的主页停在这层。

**L2 · 手写动画 SVG(本仓库的地基)** —— 把整页当成海报来设计:
自己的配色系统、字体栈、栅格、动效语言。上限是"任何能用 SVG+CSS 表达的、不需要交互的画面"。
雨、辉光、颗粒、打字机、示波器、伪 3D 都在射程内。**这一层就把 99% 的主页甩开了。**

**L3 · Actions 数据管线(本仓库已通电)** —— cron 定时抓数据 → 重渲染 → 自动提交。
README 变成"活的":语言占比、star、RSS 文章、天数……全部自动保鲜。
提交历史本身成为作品的一部分(显影批号)。

**L4 · 边缘函数按请求渲染(下一步,cinexul.com 已具备全部基建)** ——
Actions 的极限是"定时";要"每次刷新都不同 / 实时",就让 README 引用你自己的域名:

```
https://cinexul.com/profile/now.svg   ← Cloudflare Worker 按请求生成 SVG
```

Worker 里可做:访客计数(KV/D1 自增)、当前东京时间的"暗房钟"、每次刷新随机换一格胶片、
甚至根据 UA 的 `Sec-CH-Prefers-Color-Scheme` 出不同帧。唯一要点:响应头
`Content-Type: image/svg+xml` + `Cache-Control: no-cache, no-store, must-revalidate`,
camo 就会每次回源。你的博客已经是 SvelteKit + Workers,加一条 `/profile/[name].svg`
路由即可,设计令牌还能与主站共用同一套。

**L5 · 慢交互:链接矩阵 + issue 驱动** —— README 里唯一的"输入"是链接与 `<details>`:
- 把一张图切成 N 张小图各自包 `<a>`,就是"可点击的分区海报"(本页导航就是雏形);
- 链接指向 **预填参数的 issue**(`…/issues/new?title=move|e2e4`),
  Actions 监听 issue 事件 → 执行落子/留言/点亮像素 → 重渲染 SVG → 自动关闭 issue。
  经典案例:README 国际象棋、社区像素画。上限是"回合制"——任何回合制玩法都能搬进来。
  (你可以做一个「访客留灯」:任何人开一个 issue,你的雨夜车窗里就多亮一盏窗。)

**L6 · 预渲染任意画面** —— README 支持 GIF / APNG / **动画 WebP**。
于是 Actions 里可以:无头浏览器跑一个 Three.js / WebGL / 着色器场景 → 逐帧截图 →
ffmpeg 合成动画 WebP → 提交。理论上限:**任何离线渲染得出来的画面**(体积预算内)。
代价:文件大(几 MB)、无矢量清晰度、有帧率;所以本仓库选择把 L2 做到极致而不是堆 L6。

> **天花板一句话:静态视觉 ≈ 无上限(SVG/预渲染),数据 ≈ 定时(Actions)或实时(边缘函数),
> 交互 ≈ 链接与回合制(issue 驱动)。唯一做不到的是"页面内实时响应鼠标键盘"。**

## 三、本仓库逐效果拆解

整页由 `profile/render.py` 生成(纯标准库,~700 行)。伪随机数用定种子的 mulberry32
(与设计提案同款),**同一份数据渲染出的 SVG 字节级一致**——diff 永远干净。

### hero.svg · 雨夜车窗
- **夜色底**:三段线性渐变(`#0a1523 → #071019 → #04060b`)+ 地平线雾蓝/琥珀椭圆(高斯模糊 14px)。
- **散景灯火**:13 枚模糊圆(琥珀 7 / 尾灯红 2 / 雾蓝 2 / 米白 2),每枚带独立漂移 + 闪烁动画
  (CSS 变量注入相位);**全页只允许一粒品红**,是致敬主站糖果色的信号灯。
- **雨**:两层深度共 70 条线段,整体 `rotate(9°)`,每条独立 `animation-duration/delay`,
  行程大于分布区间 → 无缝循环。
- **玻璃水珠**:9 颗。radial-gradient 珠体 + 高光椭圆 + 局部描边(dasharray 造残缺环)+ 上方拖尾。
  两套 keyframes(`slipA/slipB`)模拟"黏住—滑落—再黏住",负延迟错相。
- **打字标题**:逐字符 `<text>` + `steps(1) both` 延迟出现;光标另有两条动画并行——
  `steps(7)` 跳步前进 + 无限闪烁。**刻意不用 SMIL**(部分环境不稳,CSS 全平台可靠)。
- **显影副标题**:整行 CSS `filter: blur(9px) → 0` + 淡入,像相纸在显影液里浮出来。
- **胶片颗粒**:渲染器**手工编码一张 160×160 的 RGBA PNG 噪点**(标准库 zlib+struct,雾蓝色调),
  以 `<pattern>` 平铺,再用 `steps(1)` 五帧平移抖动——比实时 feTurbulence 省一个数量级的功耗。
- **末班车**:一粒尾灯红带渐变拖尾,26 秒横穿一次画面。
- 扫描线 pattern、四角取景框刻线、EXIF 一行(`50mm · ƒ/1.4 · 1/30s · ISO 3200`)、
  显影批号 + 时间戳(Actions 每次刷新)。

### strings.svg · 以光为弦
语言占比 → 弦。粗细 = 占比,颜色映射到夜色调色板(Svelte=尾灯红,TS=雾蓝,Rust=琥珀…)。
"拨弦"三件套全 CSS:① 弦身 `stroke-width` 瞬间变粗再回弹;② 辉光层透明度脉冲;
③ 一段亮光沿弦扫过——`pathLength="700"` 归一化 + `stroke-dasharray/dashoffset` 位移。
所有弦共享一个周期,`animation-delay` 排成轮奏。

### reel.svg · 走马灯
带齿孔的胶片传送带。内容画两份,`translateX(-总宽)` 线性循环 = 无缝 marquee;
两侧用线性渐变蒙版淡出,中央叠一块琥珀"灯箱热斑";整条带微微上下呼吸 + 0.5° 倾斜。
每格内容来自 feed.xml(fetch.py 注入)。

### terminal.svg · 磷光终端
- 打字的投机解法:屏幕是纯色,**给命令文字盖一块同色矩形,用 `steps(字符数)` 把矩形整块
  平移走** → 逐字揭开,视觉上就是打字,而且是纯 CSS。输出行则整行瞬间弹出(延迟排队)。
- 磷光辉光 = 整组一个 `feDropShadow`(单滤镜,便宜);扫描线 pattern + 0.14s 微闪烁 +
  7.5s 一道刷新亮带 + 管面暗角。
- 内容全部来自 live.json:`whoami`、`uptime`(暗房天数/语言负载/近期 push)、
  `tail -f /var/log/signal.log`(博客最新文章)。

### tunnel.svg · 显影隧道
无限推进的几何解法:8 圈门框按 `0.62^i` 等比嵌套,整组做 `scale(1 → 1/0.62)` 线性循环——
缩放把第 i 圈精确送到第 i+1 圈的位置,循环点无缝。每圈画三层(红 / 雾蓝 / 米白,左右错位)
造色散;越深的圈越暗像沉在雾里;中央文字带 `steps(1)` 的偶发毛刺位移。

### 分节标题 / 导航月牌
唯一"跟随 GitHub 主题"的部件:`<picture>` + `prefers-color-scheme`,
浅色版直接采用主站阅读模式的纸面 token(暖白纸 + 陶土点缀)。
导航是六张小 SVG 各包一个 `<a>` —— "把一张图切成可点击的区域"的最小实现。

### 无障碍与克制
每张 SVG 内置 `@media (prefers-reduced-motion: reduce)` 全停动画;
每张图都有认真写的中文 `alt`;正文仍保留纯文本与语义链接,读屏器可完整获取信息。

## 四、坑与约束(踩过才知道)

1. **SMIL 不要依赖**。`<img>` 里理论可用,但省电模式 / 某些 WebView / 无头环境行为不一;
   本仓库最初用 SMIL 做打字,后来全部换成 CSS(遮盖矩形 + steps)。
2. **外部资源必死**:SVG 里的 webfont、外链图片都会被 camo/CSP 拦掉。
   字体只能用系统字体栈(本页跟设计提案同款:衬线中文走 Songti/SimSun 栈,
   等宽走 JetBrains Mono→Menlo→Consolas 栈),或把子集化字体 base64 内嵌(CJK 慎用,体积大)。
3. **文字宽度不可精测**:访客字体各异。等宽字按 `0.602em + letter-spacing` 估算,
   中文按 1em;所有依赖对齐的地方留冗余(本页的信号点位置就返过一次工)。
4. **动画要给功耗留情面**:动辉光→动透明度而不是动滤镜参数;颗粒用贴图抖动而不是实时湍流;
   单文件保持 60KB 上下,全页 250KB 内。
5. **camo 缓存**:改了 SVG 但页面没变,等 5 分钟或给 URL 加 `?v=n`。
   Actions 自动提交只改文件内容不改路径,靠 raw 的 max-age=300 自然过期。
6. **README 显示的是默认分支**:所有魔法必须合并进 `main` 才会出现在个人主页上。
7. **私有仓库红线**:fetch.py 只调用"天然只返回公开数据"的端点
   (`/users/{x}/repos`、`/events/public`、公开 RSS),私仓的名字与提交信息不可能漏进页面。

## 五、维护手册

```bash
python3 profile/render.py     # 本地重渲染(不碰网络,只读 live.json)
python3 profile/fetch.py      # 手动抓一次数据(需要网络;无 token 也能跑,限速 60 次/时)
```

- **改文案/链接/身份**:`profile/config.json`(标题、副标题、导航、兜底胶片格)。
- **改配色/版式/动效**:`profile/render.py` 顶部的设计令牌区,或对应的 `gen_*` 函数。
- **改数据口径**:`profile/fetch.py`。
- **改更新频率**:`.github/workflows/develop.yml` 的 cron(当前每 6 小时,分钟数取 23 避峰)。
- 渲染结果(`assets/*.svg`、`live.json`)由 Actions 托管,手改会被下一次显影覆盖。

## 六、点亮下一层楼(路线图)

- **L4 实时件**:在博客仓库加 `src/routes/profile/[card].svg/+server.ts`,
  返回 `image/svg+xml` + `no-store`;先做两件——"此刻东京时间的暗房钟"与
  "第 N 位路过暗房的人"(KV 自增)。README 各占一格。
- **L5 访客留灯**:`issues/new?template=lamp.yml` 链接 + Actions 监听 issue,
  每个留言者在 hero 的城市灯火里点亮一盏属于 ta 的散景(用户名哈希 → 位置/颜色),自动评论致谢并关闭。
- **L6 一格真 3D**:Actions 里用无头 Chromium 跑一段 Three.js 雨夜车窗着色器 →
  ffmpeg 合成 3 秒循环动画 WebP,作为"幻象馆"展品放在走马灯下方。
